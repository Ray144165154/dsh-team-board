# macOS DSH 真机验证 · 2026-11-11

环境：macOS，DeepSeek Harness Desktop 0.2.2-rc.1，协作台当前 Unreleased 源码。通过原生桌面界面操作，另核对看板持久化数据。未使用 fake agent 替代本次实际收件箱与模型会话。

## 发现并修复

Client 原先将 `ctx.connection.rpc.call` 返回的 `{ ok, value }` 信封直接交给页面，导致磁盘存在看板数据而页面显示 0 项目，加入版本保护后则会持续显示加载。适配层现在解包成功信封，并将 Host 错误和无效信封转成页面可见错误。测试新增对真实 Client 适配层的检查，避免只测已经解包的页面 mock 而漏掉此问题。

| 检查 | 结果 |

测试会话被要求仅操作看板工具，不读取或修改项目文件、不运行命令、不创建子代理。保留独立测试项目、完成任务和已回答决策作为验证留档；未清空或覆盖真实看板。
